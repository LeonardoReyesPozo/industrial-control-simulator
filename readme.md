Industrial Control Simulator
Simulador de un sistema de control industrial desarrollado en Python, aplicando conceptos de automatización, programación orientada a objetos y persistencia de datos en formato JSON.

Descripción:
Este proyecto simula un entorno industrial básico con sensores de temperatura y presión, evaluando condiciones de alarma y activando actuadores según una lógica de control definida.
Además, registra automáticamente eventos críticos en un archivo JSON para su posterior análisis.
El objetivo principal es aplicar principios de automatización industrial al desarrollo de software modular en Python.

Funcionalidades:
- Simulación de sensores (temperatura y presión)
- Evaluación automática de condiciones de alarma
- Activación de actuadores (bomba) según la lógica de control
- Registro de eventos críticos en un archivo JSON
- Arquitectura modular basada en POO
- Ejecución continua con manejo de excepciones

Tecnologías utilizadas:
- Python 3
- Programación Orientada a Objetos
- JSON para persistencia de datos
- Manejo de archivos
- Git y GitHub

Ejecución
python main.py
